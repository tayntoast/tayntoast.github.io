ဒီလအစောပိုင်းမှာ Ubuntu 20.04 စပြီးသုံးဖြစ်တယ်။ Windows 7 ကို မသုံးတော့ဘူးလို့ ဆုံးဖြတ်လိုက်ပြီ။ Windows 10 ကိုတော့ ရုံးက ကွန်ပြူတာတွေမှာ Craft Version နဲ့ တင်ပေးတဲ့အခါတွေမှာပဲ သုံးဖြစ်တော့တယ်။ “Windows 7 ကို Microsoft က Supporting မလုပ်တော့ဘူး” ဆိုတဲ့သတင်းက ဒီဆုံးဖြတ်ချက်ကို ပိုပြီးခိုင်မာသွားစေတယ်။

ပြီးခဲ့တဲ့ရက်က လက်ရှိသုံးနေတဲ့ ကွန်ပြူတာမှာ Windows 7 အသစ် ပြန်တင်ဖြစ်တယ်။ အဆင်မပြေဘူး။ Craft key တွေ အလုပ်မလုပ်တော့ဘူး။ ဆိုင်သွားပြီး အသစ်ဝယ်မယ် ဆိုတော့လည်း Windows 7 CD ခွေကို ဘယ်ဆိုင်မှာမှ ဝယ်မရဘူး။ ကိုယ့်မြို့မှာ ကွန်ပြူတာဆော့ဖ်ဝဲ ရောင်းတဲ့ဆိုင် မရှိဘူး။ အနီးအနား မြို့ကနေ ဝယ်ဖို့ကျတော့လည်း အခုချိန်က COVID-19 stay at home ကာလမို့ ဝယ်ဖို့မလွယ်ဘူး။ ဒီတော့ Online ကနေ Download ပြီး သုံးကြည့်တယ်။ ကျေနပ်လောက်တဲ့အဆင့်ထိမရဘူး။ ဆက်ကြိုးစားနေလည်း စိတ်ရှုပ်ရုံပဲမို့ အချိန်ကုန်မခံတော့ဘူး။ Windows 11 တောင် စျေးကွက်ထဲ ရောက်တော့မယ်။ ဒီတော့ Ubuntu ကို Main OS အဖြစ်သုံးဖို့ အချိန်တန်ပြီလို့ ထင်ပါတယ်။

လက်ရှိသုံးနေတဲ့ Laptop က Windows 10 တင်ဖို့ အရမ်းဟောင်းနေတာရယ်၊ Windows 7 ကလည်း ဂဂျီဂဂျောင် ဖြစ်လာတာတွေနဲ့ ဆိုတော့ Ubuntu ကိုသုံးဖို့ တွန်းအားဖြစ်လာတယ်။ Ubuntu ကို စသုံးမယ်ဆိုတော့ မြန်မာလိုရေးထားတဲ့စာအုပ် ရှိပါတယ်။ သေချာနားလည်အောင် ဖတ်ပြီး စမ်းကြည့်တယ်။ Ubuntu ကို တော်တော်လေး သဘောကျသွားတယ်။

> ➥ [[Ubuntu for you — by Ei Maung](https://eimaung.com/ubuntu-for-you/)] [[pdf](https://goo.gl/NU5HIG)]

အခုချိန်ထိတော့ CLI တွေနဲ့ အသားကျအောင် ကြိုးစားနေတုန်းပဲ။ CLI တွေနဲ့အသားကျအောင် လုပ်နေရတော့ ငယ်ငယ်က ဂစ်တာတီးသင်ခါစ အချိန်တွေကို ပြန်အမှတ်ရမိတယ်။ Chords နဲ့ လက်ခတ်ကို Rhythm မိလာအောင် အရင်ဆုံးလေ့ကျင့်ယူရသလိုမျိုးပဲ။ Rhythm မမိသေးခင်မှာတော့ ဘယ်ဘက်လက်က C-Am-Dm-G Round Cords တွေကို မှတ်မိနေအောင် လုပ်ရတယ်။ ညာဘက်လက်ကလည်း လက်ခတ် Timing နဲ့ Beats တွေကို မှန်အောင်တီးရတယ်။ Chords နဲ့ Beats Timing ညီသွားရင်တော့ သီချင်းလေးတွေ တဖြည်းဖြည်း တိုးကျင့်သွားရုံပါပဲ။
